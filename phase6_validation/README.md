# Phase 6 — Validation

**Goal:** Extract room dimensions via RANSAC plane fitting and measure the real error against ground truth.

**Gate:** A measured error budget, from tape-measured rooms.

**Status:** Not started — blocked on Phase 5.

Accuracy is a *result*, not an assumption. A few centimetres indoors is
achievable with solid calibration and loop closure, but do not quote a number
until this phase produces one.

Measure against tape-measured ground truth in a real room: wall-to-wall
distances, doorway widths, ceiling height. Report the distribution, not the best
case.
